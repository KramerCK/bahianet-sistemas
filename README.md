# BahíaNet Sistemas

Repositorio utilizado para gestionar los archivos del departamento de sistemas de BahíaNet.

## Archivos principales
- `servidores.txt`: Inventario de los servidores actuales.
- `monitorizacion.txt`: Propuesta del sistema de monitorización.
